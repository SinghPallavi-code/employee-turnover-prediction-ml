Employee Turnover Prediction using Machine Learning

Project Overview
This project focuses on predicting employee turnover using machine learning techniques. The goal is to identify employees at risk of leaving and provide actionable insights for retention strategies.

Business Problem
Employee turnover is a critical issue impacting organizational performance. This project helps HR teams:
- Identify high-risk employees
- Understand key drivers of attrition
- Design targeted retention strategies

Dataset
- Source: Kaggle HR Dataset
- Features include satisfaction level, evaluation score, working hours, projects, salary, etc.

Approach

1. Data Preprocessing
- Handled missing values
- Converted categorical variables using encoding
- Addressed class imbalance using SMOTE

2. Exploratory Data Analysis (EDA)
- Correlation analysis
- Distribution plots
- Feature importance insights

3. Machine Learning Models
- Logistic Regression
- Random Forest
- Gradient Boosting

4. Model Evaluation
- Accuracy, Precision, Recall, F1-score
- ROC-AUC Curve
- Confusion Matrix
- Cross-validation (5-fold)

5. Key Insights
- Low satisfaction and high workload are major drivers of attrition
- Certain employee clusters show higher risk patterns

6. Business Impact
- Enables proactive retention strategies
- Helps HR teams reduce turnover costs
- Supports data-driven decision-making
